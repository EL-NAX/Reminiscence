## 📖 Story

<div align="center">

> *"In a world ruled by the absolute laws of the Creator,<br/>
> every intent of evil is punished by a mysterious curse."*

</div>

Seven years ago, **Amari** — Krieger's childhood friend — was forcibly taken by the royal knights. Since that day, Krieger has trained relentlessly for one purpose: **to bring her home.**

But the royal fortress has never been breached by commoners. To cross the forbidden boundary, how far is Krieger willing to challenge fate and endure the Creator's judgment?

Follow his journey through **quiet villages, dark forests, haunted caves, and the heart of the enemy's fortress** — where every choice brings him closer to the truth.

## 🚀 Getting Started

<br/>

### 📋 Prerequisites

| Tool | Version | Link |
|:-----|:--------|:----:|
| **Godot Engine** | 4.x (.NET) | [Download](https://godotengine.org/download/) |
| **.NET SDK** | 8.0+ | [Download](https://dotnet.microsoft.com/download) |
| **Git + Git LFS** | Latest | [Download](https://git-lfs.github.com/) |

<br/>

### ⚙️ Installation

```bash
# 1 ─ Clone the repository
git clone https://github.com/EL-NAX/Reminiscence.git
cd Reminiscence

# 2 ─ Initialize Git LFS (untuk asset besar)
git lfs install
git lfs pull

# 3 ─ Buka project di Godot 4 (.NET version)
#     File → Import → pilih project.godot

# 4 ─ Setup C# solution
#     Project → Tools → C# → Create C# Solution

# 5 ─ Build project
#     Tekan Ctrl + Shift + B

# 6 ─ Run the game
#     Tekan F5
